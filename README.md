# producergroupdot.github.io

프로듀서그룹 도트 웹사이트

작업 규칙은 [CLAUDE.md](CLAUDE.md) 에 있습니다. 이 문서는 **사진 파일을 넣는 방법**만 다룹니다.

---

## 사진 넣는 법

빌드 도구가 없습니다. 아래 규칙대로 파일을 폴더에 넣고 커밋하면 그대로 사이트에 나옵니다.

### 폴더와 파일명

```
img/
  works/<작업ID>/01.jpg   02.jpg   03.jpg …    작업 사진
  works/<작업ID>/poster.jpg                     포스터
  artists/<예술가ID>.jpg                        예술가
  producers/<프로듀서ID>-01.jpg  -02.jpg …      프로듀서 얼굴 (About 네 칸)
  about/together/01.jpg  02.jpg …               About '함께' 가로 띠
  home/<이름>.jpg                               홈 전용 (파노라마 · 세로)
```

**About 페이지의 사진 두 가지는 파일만 넣으면 됩니다. JSON은 안 고쳐도 됩니다.**

- `img/producers/heejin-01.jpg` 처럼 넣으면 About의 그 사람 칸 오른쪽 위 원에 들어갑니다.
  한 사람에 여러 장 넣으면 페이지를 열 때마다 그중 하나가 무작위로 나옵니다.
  `-01` 부터 `-06` 까지 찾습니다. 프로듀서 ID는 `heejin` · `bongmin` · `jisun` · `miseon`.
- `img/about/together/01.jpg` 부터 `12.jpg` 까지 넣으면 둥지230 배너 아래 '함께' 띠에 차례로 들어갑니다.
  없는 번호는 그냥 건너뜁니다. 중간이 비어도 괜찮습니다.

여섯 장·열두 장보다 많이 넣고 싶으면 `data/producers.json` 의 `photos`,
`data/about.json` 의 `together` 에 파일 목록을 적으면 그쪽이 우선합니다.

폴더 안에 무엇이 들어 있는지, 무엇을 아직 못 구했는지는 [img/README.txt](img/README.txt) 에
정리돼 있습니다. 사진을 넣거나 뺄 때 그 파일도 같이 고쳐주세요 — 촬영자 크레딧이 거기 있습니다.

- `<작업ID>` 는 `data/works.json` 의 `id` 와 **똑같이** 씁니다. 영문 소문자와 하이픈만.
  예 — 〈싱크 디 싱크〉는 `id: "sync-de-sync"` 이므로 `img/works/sync-de-sync/01.jpg`
- 번호는 `01`, `02` … 두 자리로. `1.jpg` 는 안 됩니다.
- `<프로듀서ID>` 는 `data/producers.json` 의 `id` — `heejin` · `bongmin` · `jisun` · `miseon`

### 크기와 비율

| 쓰임 | 비율 | 최소 크기 |
|---|---|---|
| 작업 사진 (가로) | 3:2 | 긴 변 1600px |
| 작업 사진 (세로) | 3:4 | 긴 변 1200px |
| **홈 파노라마** (`img/home/`) | **5:2 로 미리 잘라서 넣기** | 폭 2000px |
| 포스터 | 원본 비율 그대로 | 폭 1200px |

홈 파노라마는 **반드시 5:2 로 잘라서** 넣어주세요. 자르지 않고 넣으면 화면이 알아서
가운데를 잘라내는데, 그러면 사람 머리가 잘립니다.

포스터는 자르지 않습니다. 원본 비율 그대로 넣으면 크림색 여백 안에 통째로 들어갑니다.

### 표지 사진 고르기

**보통은 아무것도 안 해도 됩니다.** 폴더에 `01.jpg` 를 넣으면 그게 표지가 됩니다.
`01.jpg` 가 없으면 `poster.jpg` 를 찾습니다(포스터만 있는 작업이 그렇습니다).
둘 다 없으면 담당 프로듀서 색면 + `사진 준비 중` 으로 나옵니다.

다른 사진을 표지로 쓰고 싶을 때만 `data/works.json` 의 `cover` 를 고칩니다.

```json
"cover": "img/works/sync-de-sync/03.jpg"
```

홈의 사진 자리는 칸 비율이 정해져 있어서 미리 잘라둔 홈 전용 파일을 따로 씁니다.
`homePhotos` 가 자리마다 어떤 파일을 쓸지 정합니다.

```json
"homePhotos": { "mosaic-wide-a": "img/home/ganghwa-panorama.jpg" }
```

자리 이름은 `mosaic-tall`(가운데 세로 3:4) · `mosaic-wide-a` · `mosaic-wide-b`(아래 파노라마 5:2) 입니다.
홈 전용 파일이 없으면 그 작업의 표지로 떨어집니다.

### 임시로 넣는 사진

정식 사진이 아직 없어서 급한 대로 넣는 사진은 **파일명 앞에 `TEMP-` 를 붙이세요.**

```
img/works/gwantong-18/TEMP-01.jpg
```

카드 왼쪽 위에 `임시 이미지` 라벨이 자동으로 붙습니다. JSON은 건드릴 필요 없습니다.
정식 사진으로 바꿀 때는 `TEMP-` 를 뗀 이름으로 넣으면 라벨도 같이 사라집니다.

### 촬영자 크레딧

**촬영자를 모르는 사진은 올리지 않습니다.** 크레딧이 없는 사진은 폴더에 넣지 말고,
누가 찍었는지 확인한 다음에 넣어주세요.

### 하면 안 되는 것

- 구글 포토·구글 드라이브 주소를 그대로 쓰지 마세요. 앨범 설정이 바뀌면 전부 깨집니다.
  반드시 파일을 내려받아 `img/` 안에 넣습니다.
- 파일을 지우지 마세요. 화면에서 빼고 싶으면 `data/works.json` 에서 `cover` 를
  비우면 됩니다. 파일은 그대로 둡니다.

## 로컬에서 열어보기

`index.html` 을 브라우저에 바로 끌어다 놓으면 데이터를 못 읽습니다.
저장소 폴더에서 아래 한 줄을 실행하고 http://127.0.0.1:8000 을 여세요.

```sh
python3 -m http.server 8000
```
