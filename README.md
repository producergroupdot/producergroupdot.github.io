# producergroupdot.github.io

프로듀서그룹 도트 웹사이트

작업 규칙은 [CLAUDE.md](CLAUDE.md) 에 있습니다. 이 문서는 **사진 파일을 넣는 방법**만 다룹니다.

---

## 사진 넣는 법

빌드 도구가 없습니다. 아래 규칙대로 파일을 폴더에 넣고 커밋하면 그대로 사이트에 나옵니다.

### 폴더와 파일명

```
img/
  works/<작업ID>/01.jpg   02.jpg   03.jpg …    작업 사진
  artists/<예술가ID>.jpg                        예술가
  producers/<프로듀서ID>.jpg                    프로듀서
  home/<이름>.jpg                               홈 전용 파노라마
```

- `<작업ID>` 는 `data/works.json` 의 `id` 와 **똑같이** 씁니다. 영문 소문자와 하이픈만.
  예 — 〈싱크 디 싱크〉는 `id: "sync-de-sync"` 이므로 `img/works/sync-de-sync/01.jpg`
- 번호는 `01`, `02` … 두 자리로. `1.jpg` 는 안 됩니다.
- `<프로듀서ID>` 는 `data/producers.json` 의 `id` — `heejin` · `bongmin` · `jisun` · `miseon`

### 크기와 비율

| 쓰임 | 비율 | 최소 크기 |
|---|---|---|
| 작업 사진 (가로) | 3:2 | 긴 변 1600px |
| 작업 사진 (세로) | 3:4 | 긴 변 1200px |
| **홈 파노라마** (`img/home/`) | **5:2 로 미리 잘라서 넣기** | 폭 2000px |
| 포스터 | 원본 비율 그대로 | 폭 1200px |

홈 파노라마는 **반드시 5:2 로 잘라서** 넣어주세요. 자르지 않고 넣으면 화면이 알아서
가운데를 잘라내는데, 그러면 사람 머리가 잘립니다.

포스터는 자르지 않습니다. 원본 비율 그대로 넣으면 크림색 여백 안에 통째로 들어갑니다.

### 표지 사진 고르기

작업 인덱스와 홈에 나오는 표지는 `data/works.json` 의 `cover` 가 가리킵니다.
기본값은 `01.jpg` 이고, 다른 사진을 표지로 쓰고 싶으면 그 줄만 고치면 됩니다.

```json
"cover": "img/works/sync-de-sync/01.jpg"
```

홈 아래쪽 파노라마 두 칸은 따로 `homePhoto` 를 봅니다.

```json
"homePhoto": "img/home/ganghwa-wide.jpg"
```

**파일이 아직 없어도 사이트는 깨지지 않습니다.** 사진 자리에 담당 프로듀서 색면과
`사진 준비 중` 이라는 작은 글씨가 대신 들어갑니다. 파일을 넣으면 그 자리가 사진으로 바뀝니다.
경로를 미리 적어두어도 괜찮습니다.

### 임시로 넣는 사진

정식 사진이 아직 없어서 급한 대로 넣는 사진에는 표시를 남겨주세요.
카드 왼쪽 위에 `임시 이미지` 라벨이 붙습니다.

```json
"cover": "img/works/energy/01.jpg",
"coverTemp": true
```

나중에 정식 사진으로 바꿀 때 `coverTemp` 줄을 지우면 됩니다.

### 촬영자 크레딧

**촬영자를 모르는 사진은 올리지 않습니다.** 크레딧이 없는 사진은 폴더에 넣지 말고,
누가 찍었는지 확인한 다음에 넣어주세요.

### 하면 안 되는 것

- 구글 포토·구글 드라이브 주소를 그대로 쓰지 마세요. 앨범 설정이 바뀌면 전부 깨집니다.
  반드시 파일을 내려받아 `img/` 안에 넣습니다.
- 파일을 지우지 마세요. 화면에서 빼고 싶으면 `data/works.json` 에서 `cover` 를
  비우면 됩니다. 파일은 그대로 둡니다.

## 로컬에서 열어보기

`index.html` 을 브라우저에 바로 끌어다 놓으면 데이터를 못 읽습니다.
저장소 폴더에서 아래 한 줄을 실행하고 http://127.0.0.1:8000 을 여세요.

```sh
python3 -m http.server 8000
```
